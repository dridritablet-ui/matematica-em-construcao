# Matemática em Construção

Plataforma de estudos de Matemática em 20 semanas.

## Publicar no GitHub Pages
1. Envie `index.html`, `styles.css` e `app.js` para a raiz do repositório.
2. Abra **Settings → Pages**.
3. Em **Build and deployment**, selecione **Deploy from a branch**.
4. Escolha a branch `main` e a pasta `/ (root)`, depois clique em **Save**.
5. Aguarde a publicação.

## Estrutura
- `index.html`: estrutura da plataforma.
- `styles.css`: identidade visual responsiva.
- `app.js`: curso, progresso e cadernos.

## Observação sobre materiais
O livro principal previsto é *O Algebrista*. As páginas/capítulos exatos, links de videoaulas e intervalos dos vídeos ainda precisam ser conferidos na edição e nos materiais escolhidos. Por isso, a plataforma não inventa referências; os campos aparecem associados a cada assunto para serem preenchidos.

O progresso e os cadernos são salvos no armazenamento local do navegador/dispositivo. Para não perder os registros, use o mesmo navegador e dispositivo.
